# Ollantay — Raíces Vivas

Adaptación audiovisual del relato tradicional Ollantay y propuesta de Desarrollo de Software orientada a la preservación de memoria cultural.

## Raíces Vivas

Raíces Vivas es una propuesta de plataforma digital para registrar, organizar y preservar relatos culturales mediante recursos multimedia.
